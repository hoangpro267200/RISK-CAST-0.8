## 🚀 Quick Commands

### Run with Default Settings
```bash
# Mixed workload, 50 users, 5 minutes
python tests/load/run_load_tests.py --scenario mixed
```

### Custom Parameters
```bash
python tests/load/run_load_tests.py \
  --scenario mixed \
  --users 150 \
  --spawn-rate 15 \
  --duration 15m \
  --host http://staging.riskcast.com
```

### With Web UI
```bash
cd tests/load
locust -f locustfile.py MixedWorkloadUser --host http://localhost:8000
# Open http://localhost:8089
```

### Distributed Testing
```bash
# Master
locust -f tests/load/locustfile.py MixedWorkloadUser --host http://localhost:8000 --master

# Workers (separate terminals)
locust -f tests/load/locustfile.py --worker --master-host=localhost
locust -f tests/load/locustfile.py --worker --master-host=localhost
locust -f tests/load/locustfile.py --worker --master-host=localhost
```


### 1. Event Hooks

```python
@events.request.add_listener
def on_request(request_type, name, response_time, **kwargs):
    # Custom logging, metrics, alerts
    pass

@events.test_start.add_listener
def on_test_start(environment, **kwargs):
    # Setup before test
    pass

@events.test_stop.add_listener
def on_test_stop(environment, **kwargs):
    # Cleanup and reporting
    pass
```

### 2. Distributed Testing
```
Master coordinates multiple workers:

         Master
        /  |  \
       /   |   \
   Worker Worker Worker

- Scale to thousands of users
- Run on multiple machines
- Aggregate results
```

### 3. Custom User Behavior
```python
class CustomUser(RiskcastUser):
    @task
    def custom_workflow(self):
        # Multi-step workflow
        quote = self.request_quote()
        if quote:
            self.get_quote_details(quote["id"])
            if self.should_accept():
                self.accept_quote(quote["id"])
```

### 4. Response Time SLAs
```python
with self.client.get(..., catch_response=True) as response:
    if response.elapsed.total_seconds() > 1.0:
```
